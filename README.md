# Kabilan S — Developer Portfolio

A simple, responsive portfolio built with HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and project links
- `style.css` — responsive styling
- `script.js` — mobile navigation and current footer year

## Included sections
- Intro
- About and education
- Skills
- Projects
- Experience and learning
- Contact (email and GitHub)

## Publish with GitHub Pages
1. Create a public repository named `Kabil-S.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. After deployment completes, visit `https://kabil-s.github.io/`.

GitHub Pages hosts this static portfolio; it does not run Django or Python backends.
